# Patient state: before and after trimming

Generated by `site/scripts/trim-report.ts` from `data/synthea-nj.json` (synthetic Synthea patients). No API calls.

**What changed:** each item is now one short line instead of a JSON object (most of the saving). Social/admin findings and visit boilerplate (forms filled in, referrals, discharge steps) are dropped. Dental work is folded into one line. Lab orders are kept and labelled "test ordered, no result on file". Pregnancy entries, dental conditions and minor acute illnesses are all kept. Rules: `site/src/engine/trim.ts`. Code-evaluated criteria are not affected.
